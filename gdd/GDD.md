**HIGH CONCEPT STATEMENT**

The current state of the game right now features the "run and gun" with only a few enemies for now. This gameplay is inspired by the game contra where enemies would go towards you but this level in the prototype, for now, has no hostile enemies This is the basis of what is planned. 





**FORMAL ELEMENTS**

* Players - This is a single-player action/adventure game. You play as The Wanderer
* Objectives - Navigate the map and eliminate enemies to progress
* Rules - You can't go off the map

&#x09;  - You can shoot non-hostile mobs

&#x20;         - You can avoid enemies if you choose to

* Procedures - run to shoot 

&#x09;       - shoot enemies/mobs

&#x09;       -

* Resources - none yet
* Conflict - obstacles
* Boundaries - This is set in a fictional world
* Outcome - Navigate the area and head to the next level



**CORE LOOP DESCRIPTION**

As of now, the core loop is to shoot enemies, navigate the map, and head to the next area.
